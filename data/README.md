Dataset abstract : 	The first Cassini Solar Conjunction Experiment (SCE1) Raw Data Archive is a time-ordered collection of radio science raw data acquired during the Quiet Cruise subphase of the Cassini mission.

The files are the necessary files to extract the position from Cassini Spacecraft, as generated with ODP Legacy software.
